# 🎭 Telegram Roleplay Bot (Gemini & OpenRouter)

Полнофункциональный Telegram-бот для ролевых игр (Roleplay / RP), свиданий, романтики и персонажей (девушки, аниме-тян, фэнтези) на базе **Google Gemini** и **OpenRouter (Uncensored 18+)**.

---

## 🚀 Как поставить бота на хостинг (Сервер 24/7)

Чтобы бот работал круглосуточно без включенного домашнего компьютера, его нужно запустить на виртуальном сервере (VPS) или в облаке.

### Шаг 1. Аренда сервера (VPS)
Подойдет любой дешевый VPS на **Ubuntu 22.04 / 24.04** (стоимость от 100–250 руб/мес на сервисах вроде *Aeza, Timeweb Cloud, Beget, Selectel, VDSina*). Минимальных характеристик (1 vCPU, 1 GB RAM) хватит с головой.

---

### Шаг 2. Загрузка файлов на сервер
1. Установите на компьютер бесплатную программу **WinSCP** или **FileZilla**.
2. Подключитесь по SFTP/SSH к вашему серверу (по IP и паролю от хостинга).
3. Скопируйте папку с ботом на сервер (например, в `/opt/telegram_rp_bot` или `/root/telegram_rp_bot`).
   > 💡 Обязательно скопируйте файл базы данных `bot_data.db`, чтобы сохранить историю персонажей!

---

### Шаг 3. Запуск бота (выберите один из вариантов)

#### Вариант А. Через Docker (Рекомендуется — в 1 команду)
На сервере выполните:
```bash
cd /root/telegram_rp_bot
docker compose up -d --build
```
* Бот запустится в фоне и будет автоматически перезапускаться при сбоях или перезагрузке сервера.
* Просмотр логов: `docker compose logs -f`
* Остановка: `docker compose down`

---

#### Вариант Б. Через автоматический скрипт `deploy.sh`
На сервере выполните:
```bash
cd /root/telegram_rp_bot
chmod +x deploy.sh
./deploy.sh
```
Скрипт сам установит зависимости, создаст службу `systemd` и запустит бота круглосуточно.
* Проверить статус: `sudo systemctl status telegram-rp-bot`
* Просмотр логов: `sudo journalctl -u telegram-rp-bot -f`
* Перезапуск: `sudo systemctl restart telegram-rp-bot`

---

## 💻 Локальный запуск на Windows (для тестов)
Просто дважды кликните по файлу `run.bat` или выполните:
```bash
python main.py
```

---

## 🕹️ Команды бота
* `/start` — Приветствие и выбор персонажа
* `/characters` — Каталог доступных персонажей
* `/reset` — Стереть память и начать новую сцену
* `/custom` — Создать своего собственного персонажа
* `/help` — Подробный гайд по ролевой игре
